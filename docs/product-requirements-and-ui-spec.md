## 1. 文档目的

本文档定义 USB Tablet Display 从“可运行的技术原型”演进为“普通用户可以安装、连接、配置和排错的双端应用”所需的完整产品行为。

后续的界面设计、模块拆分、接口设计、开发任务和验收测试都应引用本文档中的需求编号。本文档描述用户应该看到什么、系统应该如何响应，不限定 Windows UI 必须使用 WinUI 3、WPF 或其他具体框架。

## 2. 产品定位

USB Tablet Display 通过 USB 数据线把 Android 平板变成 Windows 的真实扩展显示器。它不是主屏镜像工具：Windows 会枚举出一块独立的虚拟显示器，用户可以在两块屏幕上显示和操作不同的应用。

核心价值：

- 连接一根 USB 数据线即可增加一块低延迟副屏。
- 使用 Windows 原生扩展桌面能力，不改变用户已有的软件使用习惯。
- 平板既是显示器，也是触控和键盘输入设备。
- 默认自动工作，同时为高级用户提供分辨率、帧率、画质和诊断设置。
- 不依赖 Wi-Fi，不向公共网络开放服务。

## 3. 用户与主要场景

### 3.1 目标用户

- 需要第二块屏幕查看代码、文档、聊天或监控信息的个人用户。
- 经常移动办公，希望复用现有 Android 平板的用户。
- 需要在 Windows 应用中使用平板触控的用户。
- 愿意使用 USB 数据线，但不应被要求理解 ADB、驱动、端口转发或命令行。

### 3.2 核心场景

1. 编程：主屏运行程序或资料，平板显示编辑器、终端或调试信息。
2. 办公：主屏编辑文档，平板显示会议、邮件或即时通讯。
3. 娱乐：一块屏幕播放视频，另一块屏幕浏览网页或处理轻量任务。
4. 触控：把支持触摸的 Windows 应用移动到平板并直接操作。
5. 临时扩屏：连接后自动恢复上一次显示设置，拔线后不留下幽灵屏幕。

## 4. 产品范围

### 4.1 产品化首版必须具备

- Windows 安装程序、后台服务、桌面设置应用和托盘入口。
- Android 可安装应用，以及清晰的首次连接引导。
- 自动发现一台通过 USB 连接的平板。
- 创建和移除 Windows 虚拟扩展显示器。
- 720p、1080p、1200p、1600p 的 60Hz 模式。
- D3D11 纹理零拷贝硬件 H.264 编码和 Android 硬件解码。
- 目标 1080p60；性能不足时自动降级。
- 单点、多点触控、基础手势和软键盘输入。
- 断线检测、自动重连、连接测试和可读诊断。
- 设置保存、恢复默认、日志导出和版本信息。

### 4.2 产品化首版不包含

- iPad、macOS、Linux 客户端。
- 无线连接和跨网络远程访问。
- 同时连接多台平板。
- 音频传输。
- HDR、受保护 DRM 内容传输。
- 压感笔、倾斜角和专业绘图板模式。
- 云账户、云同步和必须联网的功能。

### 4.3 后续候选能力

- 90Hz、120Hz 显示模式。
- H.265/AV1 编解码。
- USB 与局域网连接方式切换。
- 多设备配置档案。
- 手写笔与压感。
- 音频输出到平板。

## 5. 当前原型与目标产品的差距

| 能力 | 当前原型 | 目标产品 |
|---|---|---|
| Windows 启动 | PowerShell/控制台启动 | 安装后从开始菜单或托盘启动 |
| 权限 | 启动时依赖开发脚本提权 | 驱动一次安装，普通设置不反复弹 UAC |
| 设备连接 | ADB forward/reverse | 面向用户的 USB 自动发现与配对 |
| 显示 | 已是真实扩展屏 | 应用内控制启停、分辨率和布局入口 |
| 编码 | NVIDIA H.264、D3D11 零拷贝 | 自动选择编码器、自动降级、可配置 |
| Android | 直接进入全屏等待/显示页 | 首页、引导、显示页、快捷设置、诊断页 |
| 输入 | 原生触控回传 | 模式开关、手势、软键盘、坐标校准 |
| 状态 | 控制台及日志 | 双端实时状态、提示、测试连接 |
| 故障恢复 | 部分自动重连 | 状态机驱动、明确重试和修复建议 |
| 升级 | 手工构建安装 | 应用升级、驱动兼容检查和安全回滚 |

## 6. 总体系统设计

Windows 侧应拆分为三个独立职责，避免关闭设置窗口就导致副屏消失：

1. **USB Tablet Display Driver**

   UMDF/IddCx 间接显示驱动，负责创建虚拟显示器、上报模式、接收交换链。
2. **USB Tablet Display Service**

   后台引擎，负责 USB 发现、会话、抓帧、编码、传输、输入注入、恢复与日志。服务应在用户关闭设置窗口后继续运行。
3. **USB Tablet Display Desktop**

   普通权限桌面应用和托盘图标，通过受限的本机 IPC 与服务通信，只负责呈现状态和修改设置。

Android 侧包含：

1. **连接与配对模块**：识别 USB 会话、验证电脑身份、自动重连。
2. **视频模块**：协议解析、`MediaCodec` 解码、Surface 渲染。
3. **输入模块**：触摸、手势、软键盘和方向映射。
4. **界面模块**：连接首页、全屏显示、快捷设置、诊断和帮助。

推荐数据流：

```text
Windows Desktop UI ──IPC──> Windows Service ──控制──> IDD Driver
                                     │                  │
                                     │        D3D11 桌面纹理
                                     │                  ▼
Android Surface <──视频── USB <── NVIDIA/其他硬件编码器
Android 输入    ──输入──> USB ──> Windows Touch/Keyboard 注入
```

## 7. 统一体验原则

- **连接优先**：打开应用后第一眼应看到“是否已连接”和下一步操作。
- **默认可用**：普通用户无需理解码率、编码器或驱动版本即可使用。
- **渐进显示**：常用设置在主页，高级参数放在高级设置中。
- **状态可解释**：不能只显示“失败”，必须指出失败阶段、原因和修复操作。
- **危险操作明确**：驱动重装、清除配对、重置所有设置必须二次确认。
- **两端一致**：电脑和平板对连接状态、设备名、分辨率和帧率的描述一致。
- **显示不中断**：打开或关闭设置窗口、切换页面不应中止当前扩展屏会话。

## 8. Windows 桌面端信息架构

### 8.1 主窗口

- 默认尺寸：`960×680`，最小尺寸 `820×600`。
- 左侧固定导航栏约 200px，右侧为内容区。
- 窗口顶部显示产品名、当前设备和全局连接状态。
- 关闭按钮默认最小化到托盘；可在常规设置中改为完全退出。

导航项：

1. 首页
2. 显示
3. 画质与性能
4. 输入
5. 设备
6. 诊断
7. 设置
8. 关于

首页要求：

- 未连接时显示大号“连接平板”引导卡片和“测试连接”按钮。
- 已检测 USB 但未建立会话时显示设备名和具体阻塞原因。
- 已连接时提供“停止扩展屏”和“打开 Windows 显示设置”。
- 实时指标每秒更新一次，不因短时抖动频繁变色。
- 严重错误在窗口顶部显示可关闭横幅，并提供“查看详情”。

### 8.3 显示页

功能要求：

- 选择显示用途：扩展、复制、暂时仅显示。
- 显示虚拟屏编号、名称和相对位置示意图。
- 分辨率选择：1280×720、1920×1080、1920×1200、2560×1600。
- 刷新率：首版 30/60fps；120fps 标记为实验性并仅在能力检测通过时显示。
- 方向：自动、横向、纵向、横向翻转、纵向翻转。
- Windows 缩放入口：100%、125%、150%、175%、200%；实际应用由 Windows 完成。
- “打开系统显示设置”按钮用于排列屏幕、设置主屏和高级缩放。
- “让副屏位于主屏右侧”快捷操作，用于处理鼠标找不到副屏的问题。
- 分辨率或方向变更前提示可能短暂黑屏，成功后自动恢复会话。

### 8.4 画质与性能页

预设模式：

| 预设 | 目标 | 默认行为 |
|---|---|---|
| 自动（默认） | 稳定与清晰平衡 | 根据丢帧、编码耗时和带宽动态调整 |
| 低延迟 | 鼠标与触控响应 | 较短缓冲、较低码率、允许轻微画质下降 |
| 高清晰 | 文字和图片质量 | 提高码率，允许略高延迟 |
| 省电 | 降低电脑和平板功耗 | 30fps、较低码率和分辨率 |
| 自定义 | 高级用户 | 开放详细参数 |

自定义设置：

- 编码器：自动、NVIDIA、Intel、AMD、软件回退。
- 编码格式：H.264；H.265 在双方支持时显示“实验性”。
- 帧率上限：30、60，后续加入 90、120。
- 码率：自动或 2～50 Mbps；1080p60 默认 8 Mbps。
- 关键帧间隔：自动、1 秒、2 秒、5 秒。
- 自动降级开关。
- 丢帧策略：优先实时、优先完整。
- 性能信息：GPU 编码器名称、零拷贝是否启用、捕获/编码耗时。
- “运行 30 秒性能测试”按钮：播放测试动画并给出建议配置，不改变用户窗口内容。

### 8.5 输入页

- 总开关：“允许平板控制电脑”。
- 模式：
  - 原生触控：向 Windows 注入 Touch，默认模式。
  - 触控板：平板表面控制鼠标，不要求手指位置与屏幕绝对对应。
  - 仅显示：不发送任何输入。
- 单指：点击、拖动。
- 双指：滚动；可选择自然方向。
- 双指缩放：注入 Windows 缩放手势，可单独关闭。
- 长按：右键或长按触摸，用户可选择。
- 软键盘按钮及自动弹出开关。
- 物理键盘回传开关。
- Windows 键、Alt+Tab、Ctrl+Alt+Delete 等系统组合键应分级处理；无法安全注入的组合键给出说明。
- 坐标校准：显示四角目标并验证方向、缩放和触控落点。
- “将鼠标移回主屏”应急按钮，并保留可配置快捷键。

### 8.6 设备页

- 显示已发现设备：设备名称、型号、Android 版本、USB 状态和配对状态。
- 首版同一时间只能选择一台平板。
- 已配对设备列表支持重命名、忘记设备和查看最后连接时间。
- 新设备首次连接必须在两端显示同一六位配对码，由用户确认。
- “自动连接此设备”默认开启。
- “仅在平板已解锁时连接”默认开启。
- 显示 USB 连接类型：开发 ADB、USB 网络、自定义 Accessory。
- ADB 仅在“开发者选项”开启后显示，不出现在普通用户默认流程。

### 8.7 诊断页

诊断页分为“连接测试”“实时指标”“日志”三个区域。

连接测试按顺序执行：

1. Windows 服务是否运行。
2. 驱动包是否安装且签名有效。
3. 虚拟显示设备能否创建。
4. USB 数据设备是否枚举。
5. 平板应用是否在线并完成配对。
6. 控制通道是否可用。
7. 视频通道能否发送测试帧。
8. Android 是否成功解码和呈现测试帧。
9. 输入回传通道是否可用。

每一步显示等待、通过、警告或失败，并提供针对性操作。例如：

- “当前数据线可能仅支持充电，请更换支持数据传输的 USB 线。”
- “已检测到平板，但平板应用尚未打开。”
- “平板未授权这台电脑，请查看平板上的确认窗口。”
- “显示驱动未启动。需要管理员权限进行修复。”
- “硬件编码器不可用，已回退到软件编码，帧率可能降低。”

实时指标至少包含：

- 捕获、编码、发送、接收、解码、呈现 FPS。
- 当前分辨率、刷新率、码率、编码器、零拷贝状态。
- 捕获、编码、传输、解码、呈现延迟及端到端估算。
- 编码丢帧、网络丢包/断流、解码丢帧、重连次数。
- Windows CPU/GPU 占用、应用内存；Android 解码器和温度警告。

日志功能：

- 默认只显示最近 200 条可读事件。
- 可切换普通/详细等级。
- “导出诊断包”生成 ZIP，包含脱敏日志、版本、能力信息和最近配置。
- 导出前列出内容；不得包含用户桌面画面、键盘内容、文件名或证书私钥。
- “复制诊断摘要”生成适合提交问题的短文本。

### 8.8 常规设置与关于页

常规设置：

- 开机启动后台服务。
- 登录后自动连接上一次设备。
- 关闭主窗口时：最小化到托盘/退出界面但保持连接/完全停止连接。
- 语言：跟随系统、简体中文、英文。
- 主题：跟随系统、浅色、深色。
- 通知：连接、断线、自动降级、错误。
- 自动检查应用更新。
- 恢复默认设置。

关于页：

- 桌面应用、服务、驱动和协议版本。
- Android 客户端版本及最低兼容版本。
- 开源许可、隐私说明、项目主页。
- “检查更新”和“复制版本信息”。

### 8.9 系统托盘

托盘图标颜色表达状态：灰色未连接、蓝色连接中、绿色已连接、橙色降级、红色错误。

右键菜单：

- 当前设备和状态（不可点击标题）。
- 开始/停止扩展屏。
- 打开 USB Tablet Display。
- 打开 Windows 显示设置。
- 将鼠标移回主屏。
- 诊断连接。
- 退出。

## 9. Android 平板端信息架构

### 9.1 页面结构

1. 首次使用引导
2. 连接首页
3. 全屏显示页
4. 显示中的快捷控制层
5. 设置
6. 连接测试与诊断
7. 关于与隐私

### 9.2 首次使用引导

最多四步，每步都允许返回：

1. 说明用途：“用 USB 把平板变成 Windows 扩展屏”。
2. 连接数据线，并说明必须支持数据传输。
3. 授权必要权限；每项权限旁解释用途。
4. 在电脑端打开 USB Tablet Display 并确认配对码。

不得在首次打开时连续弹出无解释的权限窗口。权限只在用户进入需要该能力的步骤时请求。

```text
│ │ 等待电脑端确认配对        │ │
│ └──────────────────────────┘ │
│                              │
│ 连接帮助       诊断       关于│
└──────────────────────────────┘
```

首页状态：

- 未连接 USB。
- USB 已连接但没有数据能力。
- 已发现电脑，等待配对。
- 正在连接。
- 已连接，正在建立显示器。
- 连接成功，即将进入全屏显示。
- 上次连接失败，可重试。

连接成功后默认自动进入全屏显示；用户可关闭“连接后自动全屏”。

### 9.4 全屏显示页

- 视频内容铺满可用显示区域，默认黑色背景。
- 保持屏幕常亮，隐藏状态栏和导航栏。
- 保持视频宽高比；比例不一致时使用黑边，不拉伸文字。
- 旋转时先冻结最后一帧，完成协商后切换，避免闪烁和错误触控。
- 无新帧超过 2 秒时显示半透明“画面暂时中断，正在恢复”。
- 断线超过 10 秒退出到连接首页，并保留“一键重连”。
- 单指触控默认直接传给 Windows，不应被应用自身工具栏抢占。

### 9.5 显示中的快捷控制层

为了不干扰 Windows 触控，快捷控制层通过“从屏幕右边缘向内滑动”或 Android 返回手势唤出；三秒无操作自动隐藏。

横屏布局：

```text
┌──────────────────────────────────────────────────────────────────┐
│                         Windows 副屏画面                          │
│                                                        ┌────────┐│
│                                                        │ 58 fps ││
│                                                        │触控  开 ││
│                                                        │⌨ 键盘  ││
│                                                        │旋转锁定 ││
│                                                        │设置     ││
│                                                        │断开     ││
│                                                        └────────┘│
└──────────────────────────────────────────────────────────────────┘
```

快捷项：

- 当前 FPS 和连接质量。
- 触控开关/输入模式。
- 显示软键盘。
- 旋转锁定。
- 画质预设：自动、低延迟、高清晰、省电。
- 返回应用首页。
- 主动断开。

### 9.6 Android 设置页

- 触控：开启、原生触控/触控板/仅显示、自然滚动、长按行为。
- 键盘：显示键盘按钮、自动弹出、语言和按键反馈。
- 显示：保持屏幕常亮、沉浸式、旋转锁定、画面适配方式。
- 性能：自动/低延迟/高清晰/省电；高级指标开关。
- 连接：自动连接已配对电脑、仅解锁时连接、忘记电脑。
- 外观：跟随系统、深色模式、状态浮层大小。
- 隐私：配对记录、诊断日志、清除本机数据。

Windows 是分辨率、编码器和目标帧率的最终控制端；Android 对这些项目只发送偏好请求，避免两端配置互相覆盖。生效后的结果必须同步显示在两端。

### 9.7 Android 诊断页

- USB 状态和连接方式。
- 已配对电脑及会话 ID。
- 视频连接、输入连接状态。
- 当前解码器名称、分辨率、接收/解码/呈现 FPS。
- 接收码率、队列深度、解码错误数、最近一帧时间。
- 屏幕当前/最高刷新率，例如 60Hz/120Hz。
- “测试连接”“复制诊断摘要”“导出日志”。

## 10. 视觉与交互规范

### 10.1 视觉方向

- 关键词：可靠、轻量、清晰、有线连接。
- 品牌主色建议使用青蓝色，呼应当前“叠放屏幕 + USB-C”图标。
- 状态色：绿色成功、蓝色处理中、橙色警告、红色错误、灰色未连接。
- 深色模式下视频显示页使用纯黑背景，减少黑边发灰和夜间眩光。

### 10.2 基础尺寸

- Windows 内容边距 24px，卡片间距 16px，控件高度 36～40px。
- Android 使用 8dp 网格，普通页面边距 24dp，主要按钮高度至少 48dp。
- Android 触控目标不得小于 48×48dp。
- 状态数字使用等宽数字，避免 FPS 更新时布局跳动。
- 主操作按钮每页最多一个高强调样式。

### 10.3 文案规则

- 优先使用用户可理解的词：“平板未连接”，而不是“transport unavailable”。
- 技术错误码放在详情区，不放在主提示标题。
- 每条错误至少包含“发生了什么”和“现在可以做什么”。
- 自动降级需要提示，但不应每次帧率波动都通知用户。

### 10.4 可访问性

- 支持 Windows 和 Android 系统字体缩放。
- 颜色不得是唯一状态表达方式，必须配合图标和文字。
- Windows 所有控件支持键盘焦点和屏幕阅读器名称。
- Android 快捷控制层支持 TalkBack；全屏触控与无障碍模式冲突时明确提示。

## 11. 连接与会话状态机

统一状态定义：

```text
未启动
  ↓
等待设备 ──检测到USB──> 识别设备
  ↑                         ↓
断开 <──失败/拔线── 配对/验证
  ↑                         ↓
重连中 <──异常── 建立控制通道
  ↑                         ↓
降级运行 <──性能不足── 创建虚拟显示器
  ↑                         ↓
          正常显示 <── 建立视频与输入通道
```

状态要求：

- 每次状态变化带时间戳和原因，记录到日志并同步到两端。
- 普通网络/USB抖动先自动重试，不立即销毁用户显示布局。
- 断开确认后移除虚拟显示器，默认不保留幽灵屏幕。
- 10 秒恢复目标包括发现设备、恢复控制通道、请求关键帧和恢复输入。
- 重试采用有限退避，例如 1、2、3 秒；持续失败后停止高频重试并等待用户操作或设备事件。
- 会话重建后清除所有未完成触点和按键，避免“卡键”或“手指未抬起”。

冲突规则：

- 不允许只改变界面选中项但后台未生效。
- 检测到设备能力变化时，保留用户偏好，同时显示本次实际降级值。

## 14. 安装、升级与卸载

### 14.1 Windows 安装

- 一个安装包安装桌面应用、后台服务和经过签名的驱动。
- 安装前检查系统版本、x64 架构、磁盘空间和已有版本。
- 安装驱动时解释需要管理员权限的原因。
- 安装完成后可以立即启动，不要求用户打开终端。
- 驱动安装失败时应用本体仍可打开诊断页，并提供错误详情。

### 14.2 Android 安装

- 正式版通过可信应用商店或签名 APK 分发。
- 安装后首次启动进入引导，不要求 ADB。
- 系统权限只按需申请；拒绝后提供再次授权入口。

### 14.3 升级

- UI、服务、驱动和 Android 协议分别有版本号。
- 建立连接前进行协议兼容协商。
- 应用升级不得无提示重置分辨率、配对或输入设置。
- 驱动升级失败应回滚到旧版本或让设备保持未启动状态，不能反复蓝屏/重启。

### 14.4 卸载

- Windows 卸载器停止服务、移除虚拟设备、驱动包和应用文件。
- 用户可选择保留或删除配对及设置。
- Android 卸载后由系统清除本机配对密钥和日志。

## 15. 安全与隐私

- 首次连接必须有人在两端确认，不接受静默陌生设备。
- 配对使用随机设备密钥；六位码只用于人工核对，不直接作为长期密钥。
- 会话控制和输入消息需要完整性验证及防重放序号。
- 正式连接不监听公共 Wi-Fi 网卡；开发 ADB 模式只监听回环地址。
- Windows UI 到服务的 IPC 限制为当前登录用户和受信任应用。
- 输入注入总开关随时可见，Android 显示正在控制的电脑名称。
- 不录制、不上传桌面内容；诊断默认不包含视频帧和键盘文本。
- 本地日志中的设备标识应脱敏，日志自动轮换并允许用户清除。
- 驱动和安装包在发布前必须使用符合 Windows 分发要求的签名。

| 项目 | 首版验收目标 | 理想目标 |
|---|---:|---:|
| 1080p60 实际呈现帧率 | 稳定 ≥55fps | 接近 60fps |
| 1080p60 端到端延迟 | <80ms | <40ms |
| 首次连接时间 | <15 秒 | <8 秒 |
| 已配对重连时间 | <10 秒 | <5 秒 |
| 视频断流恢复 | <10 秒 | <3 秒 |
| 连续运行 | 8 小时无崩溃 | 24 小时无明显资源增长 |
| Windows 空闲 CPU | <5% | <2% |
| Windows 活跃 CPU | 硬编路径平均 <15% | <8% |
| 日志磁盘占用 | 默认 ≤100MB | 可配置 |

性能统计必须区分“桌面没有变化所以没有新帧”和“系统来不及处理导致丢帧”，不能把静态桌面的低 FPS 错报为故障。

## 17. 错误等级与用户反馈

| 等级 | 示例 | 界面行为 |
|---|---|---|
| 信息 | 已连接、分辨率已切换 | 短暂提示或状态更新 |
| 警告 | 自动降到 30fps、软件编码 | 橙色提示，可继续使用 |
| 可恢复错误 | USB 短暂断开、解码器重建 | 自动重试并显示进度 |
| 阻塞错误 | 驱动未安装、配对失败 | 停止当前步骤，提供修复按钮 |
| 严重错误 | 服务连续崩溃、驱动异常 | 停止自动重试，保留诊断和安全退出 |

任何自动操作都应有停止入口。连续三次同类失败后，不再无限弹通知，而是在主页保持一个稳定的错误卡片。

## 18. 首版验收场景

### 18.1 安装与首次连接

1. 在干净的 Windows 11 x64 电脑安装桌面端。
2. 在 Android 10+ 平板安装客户端。
3. 连接支持数据的 USB 线，双端完成配对。
4. 无需命令行或 ADB，Windows 出现 USB Tablet Display。
5. Windows 默认进入扩展模式，平板自动显示副屏。

### 18.2 日常使用

1. 用户将不同应用分别放在主屏和副屏。
2. 用户可以从主屏侧边自然移动鼠标进入/离开副屏。
3. 平板只显示一个 Windows 光标。
4. 点击、拖动、滚动、多点触控和软键盘作用于正确位置。
5. 打开或关闭桌面设置窗口不影响显示。

### 18.3 设置

1. 在桌面端切换四种分辨率并自动恢复画面。
2. 切换横竖屏后图像比例和触控坐标正确。
3. 切换 30/60fps、自动/低延迟/高清晰预设后，两端显示实际值。
4. 切换“仅显示”后平板不再向 Windows 注入输入。

### 18.4 故障恢复

1. 拔出 USB 后结束会话并移除虚拟屏。
2. 10 秒内重新插入后自动恢复。
3. Android 熄屏、切到后台再返回后能恢复视频。
4. 视频解码器异常时请求关键帧并重建，不要求重启电脑。
5. 数据线仅充电、应用未启动、驱动未加载时显示不同提示。

### 18.5 稳定与安全

1. 1080p60 连续运行 8 小时无崩溃和明显内存增长。
2. 睡眠/唤醒、锁屏/解锁后不会留下卡住的触点或按键。
3. 未配对设备不能建立输入会话。
4. 局域网其他设备无法连接视频或输入端口。
5. 诊断包不包含桌面截图或用户输入内容。

## 19. 实施阶段与开发顺序

### 阶段 A：桌面应用骨架

- 建立 Windows Desktop、Windows Service 和本机 IPC。
- 把现有控制台中的启动、停止和状态读取迁移到服务。
- 完成首页、托盘、显示页和基础诊断页。
- 保留 ADB 作为临时连接后端，确保迁移过程中现有闭环可用。

完成标志：用户可点击应用按钮启动/停止现有 ADB 原型，不再手动运行 PowerShell。

### 阶段 B：Android 产品界面

- 重构导航和连接状态模型。
- 完成连接首页、全屏快捷层、设置和诊断页。
- 完成软键盘、仅显示模式、旋转锁定。

完成标志：日常显示和输入操作均能从 Android UI 控制。

### 阶段 C：统一配置与自动恢复

- 定义双端控制协议和设置确认机制。
- 实现分辨率/帧率/画质动态切换。
- 完整连接状态机、重连、关键帧请求和会话恢复。
- 增加性能测试和诊断包。

完成标志：常见断线和模式切换无需重启应用或手工执行命令。

### 阶段 D：产品化 USB

- 用 USB 网络或自定义 Accessory 后端替换默认 ADB 流程。
- 加入配对、身份认证和安全会话。
- 完成多厂商兼容处理和普通用户引导。

完成标志：未开启 USB 调试的普通用户可以完成首次连接。

### 阶段 E：安装、签名与发布准备

- Windows 一体化安装、升级、修复和卸载。
- 驱动正式签名/认证流程。
- Android 正式签名与分发。
- 完成长时间、兼容性、安全和回滚测试。

## 20. 首个 UI 开发迭代的边界

为了尽快从“代码启动”变为“应用启动”，第一个 UI 迭代只实现以下闭环：

1. Windows 主窗口：首页、显示、画质与性能、输入、诊断五个页面骨架。
2. Windows 后台进程接管现有虚拟显示器、视频和触控线程。
3. 首页具有开始、停止、打开显示设置、测试连接四个可用按钮。
4. 实时显示设备名、连接状态、分辨率、FPS、编码器和错误信息。
5. 设置先支持分辨率、30/60fps、码率、触控开关，并持久化到本机。
6. Android 增加连接首页和从右侧唤出的快捷控制层。
7. 开发期继续使用 ADB，但由 Windows 应用自动执行和诊断，用户不再输入命令。

这一迭代完成后再开发产品化 USB，避免同时替换界面、进程架构和传输层而难以定位问题。
