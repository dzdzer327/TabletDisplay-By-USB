# USB Tablet Display v0.2.5

用一根 USB 数据线，把 Android 平板变成 Windows 第二屏。

电脑写代码、平板放文档，两块屏幕可以显示不同内容；支持平板触控点按、拖拽，以及分辨率、帧率和码率设置。

## 下载与使用

推荐下载 Windows `Setup.exe`。需要带到另一台电脑时，可下载含安装器、APK 和中文教程的 `TestKit.zip`；单独 APK 用作手动安装备用。

1. 安装电脑端。
2. 平板开启 USB 调试，连接数据线并允许电脑授权。
3. 点击电脑端“启动扩展屏”，按平板提示允许安装配套应用。
4. 在 Windows 显示设置选择“扩展这些显示器”，将窗口拖到平板。

默认 60fps；120fps 为实验设置，需设备支持。截图和详细使用方法见仓库首页。

## 本版改进

- 修复应用设置后首个点按丢失。
- 修复横向画面在竖向平板上拉伸，黑边不再接收触控。
- 卸载遇到文件占用时保留重试入口。
- 统一安装器、APK 与体验包构建。

Windows 10 22H2 / Windows 11 x64、Android 10+。当前为预览版，需要管理员权限和 USB 调试，使用开发签名；安装器会导入项目开发证书信任。暂不支持音频、无线或软键盘文本回传。
