# v0.2.5 缺陷修复与回归

日期：2026-10-29。针对 `release-validation-2026-10-29.md`，本轮不修改历史测试结论、不上传 GitHub。

## 修改

- 输入连接：Android 增加独立 EOF 观察线程，Windows 重建触控会话后，空闲状态也会关闭旧连接并重新连接；断连手势队列清空，避免跨会话回放。
- 画面适配：SurfaceView 按源分辨率等比缩放、居中留黑边；只有有效视频区域采集触控，沿用相对该区域的归一化坐标，黑边不注入输入。
- 卸载恢复：最后才删除卸载程序、卸载脚本与安装标记；文件删除失败时保留/恢复这些入口。全局安装状态仅在载荷成功删除后清理，以便重试。
- 发布一致性：构建统一安装器后同步重建体验包，拒绝体验目录中的未知文件；增加 ZIP 内安装器/APK/验收脚本与单独产物的逐字节 SHA-256 比对。
- 120fps 排查：没有假定设置值等于实际帧率。增加 Android 窗口刷新率请求，并将测试图案的 WinForms 消息定时器替换为独立高精度调度，记录实际绘制次数，以区分测试源不足和编码不足。
- 修正测试报告中的固定 `AndroidConnected=false` 字段为 `NotProbed`，避免误报设备状态。历史报告保持原样。
