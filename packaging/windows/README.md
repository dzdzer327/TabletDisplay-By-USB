# USB Tablet Display v{{VERSION}}

这是供 GitHub 体验测试使用的预览包，可通过 USB 数据线把 Android 平板作为 Windows 扩展屏。当前连接仍采用 ADB USB 调试通道，并非最终的免调试产品版本。

普通用户推荐下载统一安装版 `TabletDisplay-Windows-x64-v{{VERSION}}-Setup.exe`，它内置 ADB 和 Microsoft 运行库。此 ZIP 是便携版本，适合已经装好下列运行依赖的测试机器。

## 1. 安装说明

1. 完整解压 ZIP，不能只从压缩包中直接运行 EXE。
2. 双击 `Setup-Windows.cmd`。脚本会下载 Google 官方 Android Platform-Tools、请求管理员权限、验证并安装显示驱动，然后创建桌面快捷方式。
3. 平板开启“开发者选项 → USB 调试”，使用支持数据传输的 USB 线连接电脑，并在平板上允许该电脑的调试授权。
4. 在电脑启动扩展屏时会自动安装或更新包内 Android 应用；相同版本跳过，更高版本不降级。请保持平板解锁并留意 USB 安装确认。独立 APK 可用于手动安装备用。

> 安全说明：当前驱动是开发用自签名驱动，不是 Microsoft 正式签名版本。安装脚本会把随包证书加入本机的“受信任的根证书颁发机构”和“受信任的发布者”。仅从你信任的 GitHub Release 下载，并先核对发布页 SHA-256。

## 2. 环境要求

- Windows 10 22H2 或 Windows 11，x64。
- Android 10（API 29）及以上。
- Windows 已启用 .NET Framework 4.8.1。
- Microsoft Visual C++ 2015-2022 x64 运行库，版本至少为 14.44.35211；统一安装版会自动配置。
- 一根支持数据传输的 USB 线；仅充电线不能使用。
- 平板允许 USB 调试。首次预览版不支持免 ADB 连接。
- 推荐 NVIDIA 显卡以使用当前低延迟硬件编码路径；具体帧率仍受 GPU、USB 和平板解码能力限制。

## 3. 首次连接

1. 在平板上启动 USB Tablet Display，保持在“等待电脑画面”。
2. 双击桌面的 `USB Tablet Display` 快捷方式，或运行本目录的 `USB Tablet Display.exe`。
3. 等待首页识别出真实 USB 平板，点击“启动扩展屏”，同意管理员提示。
4. 打开 Windows“设置 → 系统 → 显示”，选择“扩展这些显示器”，排列 USB Tablet Display 的左右位置。
5. 把窗口从主屏边缘拖入副屏。默认 60 Hz / 60fps / 8 Mbps；首页选择 120fps 并点击“应用设置”可请求 120 Hz，连接中可调整分辨率、帧率、码率与触控开关。不稳定时选择 1080p / 60fps 后应用。

请以状态区的实际显示模式、编码上限和控制器确认结果为准；平板性能浮层分别显示解码 FPS 与本机物理 Hz。静止桌面不会持续编码新帧，120fps 是实验上限而不是实际吞吐保证。Android“优先高刷新率”只作用于本机屏幕；电脑视频参数应在电脑端修改并应用。未接入的预览控件已禁用，排列、方向与缩放请在 Windows 原生显示设置中调整。

## 4. 常见故障

- **未检测到平板**：运行 `Install-ADB.cmd`，更换 USB 线或接口；在平板 USB 用途中选择“文件传输”，撤销后重新允许 USB 调试授权。
- **识别成模拟器/手机**：关闭模拟器和无线 ADB，仅保留目标平板；本版本只支持一台真实 USB Android 设备。
- **显示器没有出现**：重新运行 `Setup-Windows.cmd`，在设备管理器确认存在 `USB Tablet Display`，再从桌面端停止并重新启动扩展屏。
- **鼠标移到副屏后找不到**：在 Windows 显示设置中校准两块屏幕的位置，或使用桌面端“召回鼠标”功能。
- **黑屏、花屏或帧率低**：先降为 1920×1080、60 Hz，关闭高 GPU 占用应用，并确认平板支持 H.264 硬件解码。
- **APK 无法安装**：卸载签名不同的旧测试版后重装；卸载会清除该应用本地设置。

## 5. 卸载与恢复

1. 先在桌面端点击“停止扩展屏”。
2. 双击 `Uninstall.cmd` 并允许管理员权限。它会移除软件设备、项目驱动包、开发证书信任和桌面快捷方式。
3. 在 Android 设置中正常卸载 USB Tablet Display。
4. 删除解压后的 Windows 文件夹。ADB 仅保存在该文件夹的 `tools` 目录，不修改系统 PATH。

若驱动卸载后显示设置仍残留副屏，请重启 Windows。若卸载脚本提示驱动正在使用，也请先重启，然后再次运行脚本。

## 6. 已知限制

- 这是 v{{VERSION}} 开发预览版，尚未获得 Microsoft 正式驱动签名，不适合生产环境。
- 首次版本必须启用 Android USB 调试；尚未实现 USB 网络共享或 USB Accessory 正式连接。
- 目前只支持一台平板，不支持无线、音频、HDR、DRM 视频和压感笔。
- 120 Hz 为实验模式；硬件能力不足时应回退到 60 Hz 或更低分辨率。
- 某些受保护内容可能黑屏，这是 Windows 内容保护机制的限制。
- APK 使用开发签名；后续正式签名版本可能需要先卸载本预览版。

发布包根目录的 `MANIFEST.sha256` 可用于核对 ZIP 内文件完整性；GitHub Release 旁的 `SHA256SUMS.txt` 用于核对下载文件。
