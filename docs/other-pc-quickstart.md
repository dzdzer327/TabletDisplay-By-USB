# USB Tablet Display：其他电脑试用教程

版本：0.2.5；整理日期：2026-10-16。

## 1. 带上哪些文件

复制 `TabletDisplay-TestKit-v0.2.5.zip` 到 U 盘，带上 Android 平板和支持数据传输的 USB 线。到目标电脑上，将 ZIP 完整解压到本地文件夹，例如桌面的 `TabletDisplay-TestKit`；不要直接在压缩包中运行程序。

测试包里有：

- `TabletDisplay-Windows-x64-v0.2.5-Setup.exe`：电脑安装器，内置 ADB、Microsoft 运行库和显示驱动。
- `TabletDisplay-Android-v0.2.5.apk`：平板安装文件。
- `README-FIRST.txt`：本教程，双击可打开。
- `Test-Windows.cmd`：可选的自动安装验收入口。
- `Resume-Test.cmd`：自动验收要求重启后，用它继续。
- `Test-CleanWindows.ps1`、`Run-CleanWindowsTest.ps1`：验收脚本。
- `SHA256SUMS.txt`：包内文件校验值。

电脑需要 Windows 10 22H2 或 Windows 11 x64，平板需要 Android 10 及以上。无需安装 Visual Studio、WDK、Java 或 Android SDK。ARM 版 Windows 不属于这个 x64 驱动包的测试范围。

## 2. 直接安装体验

如果主要想试试能否正常使用，按这一节操作即可，不必运行验收脚本。

1. 双击 `TabletDisplay-Windows-x64-v0.2.5-Setup.exe`，在管理员提示中允许安装。
2. 保持默认安装目录，点击“安装”，等待结束。这个安装步骤可以离线进行。
3. 如果安装日志提示 `RESTART REQUIRED`，先重启电脑。
4. 桌面上应出现 `USB Tablet Display` 快捷方式；默认应用目录为 `C:\Program Files\USB Tablet Display`。

当前是开发预览版，安装虚拟显示驱动时会信任随包的项目开发证书。安装器不会修改 Secure Boot 或测试签名模式。若电脑的安全策略阻止安装，记录完整提示，先不要更改系统安全设置。

## 3. 准备平板

1. 在平板设置中开启“开发者选项”和“USB 调试”。多数设备需要在“关于平板”中连续点按版本号开启开发者选项，具体菜单名称因厂商而异。
2. 用 USB 数据线连接目标电脑和平板。USB 用途可以选择“文件传输”。
3. 平板弹出“允许 USB 调试”时，确认是自己的测试电脑后允许。换一台电脑需要重新授权。
4. 保持平板解锁。无需先手动安装 APK，下一节在电脑点击“启动扩展屏”时会自动检查、安装或更新并打开平板应用。部分机型会另外弹出 USB 安装确认，需要在平板上允许。

更新来源是电脑安装包内置的 APK。相同版本不重复安装，平板版本更高时保留更高版本。签名冲突时停止并显示提示，保留旧应用和数据。单独的 APK 仍可用于手动安装。

本次只连接目标平板；先关闭电脑上的 Android 模拟器。正式连接仍依赖 USB 调试。

## 4. 启动扩展屏

1. 在电脑上双击桌面的 `USB Tablet Display`。
2. 等待首页识别平板，点击“启动扩展屏”，允许这次管理员提示。
3. 打开 Windows“设置 → 系统 → 显示”，应看到第二台显示器。
4. 将多显示器模式设为“扩展这些显示器”；点击“识别”，按真实摆放位置排列两块屏幕，然后应用。
5. 将一个普通应用窗口从主屏边缘拖到平板屏幕。窗口一般仍在主屏或上次关闭的位置打开，需要先拖过去。

如果第一次没出现画面，先在 Windows 中启用扩展模式，再在桌面端停止并重新启动一次扩展屏。当前首次显示器枚举超时后不会自动恢复。

默认使用 60 Hz / 60fps / 8 Mbps。要测试 120fps，在电脑首页选择“120 fps”，再点击“应用设置”；它会同时选择副屏 120 Hz。显示页可调整分辨率和 60/120 Hz，画质页可调整 30/60/120fps 编码上限和 2～50 Mbps 码率。连接中可应用，视频会短暂重连，无需重新安装。

请看状态中的“实际显示模式”和“编码上限”，等待控制器确认，不要只看下拉框。当前编码帧率随画面变化，静止桌面不会持续产生 120 个新帧。Android“优先使用 120 Hz”只请求平板自身的物理刷新率，不控制电脑编码；性能浮层分别显示解码帧率与平板实际刷新率。硬件不支持或性能不足时不能保证 120fps，请回退到 1920×1080 / 60fps。

设置保存在当前 Windows 用户的 `%LocalAppData%\USB Tablet Display\settings.ini`；平板触控、常亮和刷新率偏好也会保留。尚未接入的预览选项已禁用，屏幕排列、方向和缩放继续通过 Windows 原生显示设置调整。

## 5. 这次重点试什么

逐项检查，并简单记下结果：

1. 安装能否完成，是否要求重启。
2. 桌面程序能否正常打开，是否识别到正确平板。
3. Windows 是否出现第二屏，能否使用“扩展”模式。
4. 普通应用窗口能否拖到平板，与主屏显示不同内容。
5. 平板点按、拖动是否能操作副屏应用。
6. 桌面端“停止扩展屏”能否退出，重新启动能否恢复。
7. 拔掉线后发生什么，再插上能否恢复；若不能，停止后重启连接是否可用。
8. 切换 60/120fps、分辨率、码率并点击“应用设置”，确认状态同步变化；静止桌面不用于判断最高帧率。

测试鼠标跨屏时，应从 Windows 显示设置中两块屏幕相接的边缘移动。主副屏排列不对时，鼠标可能从意料之外的边缘进入；找不到鼠标可尝试桌面端的“召回鼠标”。

软键盘、触控板模式和自动降级仍未接入；不能把这些预览选项计作已支持。120fps 是实验上限而非保证吞吐，需要用动态内容在真实设备上测试。

## 6. 出错时带回什么

- 出错提示的完整截图，以及问题出现在哪一步。
- 电脑的 Windows 版本、显卡型号，平板型号与 Android 版本。
- 日志目录：`C:\ProgramData\USB Tablet Display\Logs`。可以复制整个 `Logs` 文件夹。
- 如果运行了自动验收，带回测试包目录里的 `clean-windows-results` 文件夹。

常见情况：

- **电脑看不到平板**：确认 USB 调试授权，更换数据线/接口，检查平板 USB 用途。部分品牌还需要厂商提供的 ADB USB 驱动；当前包内 ADB 工具不包含所有品牌的 USB 驱动。
- **平板停在等待画面**：先检查 Windows 是否有已启用的副屏；启用扩展模式后停止并重启一次连接。
- **设备已识别但黑屏/报编码器错误**：记录显卡型号和日志；不同显卡兼容性仍待验证。
- **APK 提示签名冲突**：不要立即卸载已有应用。先记录提示；卸载旧版会清除应用本地设置，需要确认这些设置不再需要后再处理。
- **安装要求管理员账户**：需要这台电脑的管理员授权；受单位管理的电脑可能不允许安装开发驱动。

## 7. 可选：自动安装验收

如果想生成一份结构化结果，第一次安装时可以选择本节。不要先按第 2 节手动安装；脚本会自行运行同一个安装器。

1. 解压后双击 `Test-Windows.cmd`，允许管理员提示。
2. 等待脚本完成。它会检查开发环境、安装应用、检查依赖/ADB/驱动/快捷方式、启动并关闭桌面程序，再重复安装一次验证是否可正常覆盖。
3. 默认不会卸载，完成后继续按第 3～5 节连接平板。
4. 若结果为 `RestartRequired`，重启 Windows，再双击 `Resume-Test.cmd`。
5. 结果在同目录的 `clean-windows-results`。`Passed` 只表示脚本检查通过；报告里的 `RealUsbDisplay=NotTested` 表示还需要你手动连接平板验证画面。

若脚本提示发现开发环境，就不能把这台机器算作“没有开发环境”的测试机；这不等于应用不能运行。若你已经手动安装过应用，脚本也会停止，以免把已有安装误当首次安装。直接继续手动试用即可；需要重新做首次安装验收时，先正常卸载应用。

## 8. 测试结束如何卸载

1. 先在电脑桌面端点击“停止扩展屏”，关闭桌面程序。
2. 在 Windows“设置 → 应用 → 已安装的应用”中找到 `USB Tablet Display` 并卸载；也可以运行安装目录里的 `Uninstall.exe`。
3. 在平板设置里单独卸载 Android 应用（如果不再使用）。

卸载保留 Microsoft 共享运行库、安装前已有的项目驱动与证书信任，以及诊断日志。安装器本次新增的驱动和证书信任会按安装记录清理；若还有其他版本项目驱动，所需证书信任可能继续保留。

请先复制需要反馈的日志，再按自己的需要清理测试包文件。
